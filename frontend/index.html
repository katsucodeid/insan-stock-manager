PUSAT KENDALI

Ringkasan persediaan

Pantau stok yang tersedia. Status Aman berarti stok masih di atas batas minimum. Jika di bawah minimum, segera rencanakan pengadaan.

Stok tersimpan

Catat barang masuk

Total barang dihitung otomatis: (jumlah pack × isi per pack) + tambahan pcs. Contoh: 2 pack × 100 pcs + 5 pcs = 205 pcs.

Catat target produksi

Pilih outlet, lalu isi jumlah setiap varian. Total seluruh loyang dihitung otomatis dan ditampilkan sebelum target disimpan.

Ambil target yang sudah tersimpan (opsional)

Pilih target untuk mengubah request tanpa membuat transaksi ganda.

Jumlah loyang per varian

Pengaturan kemasan per varian

Centang hanya varian yang kemasannya ingin diatur khusus. Varian yang tidak dicentang tetap memakai hitungan normal.

Setiap varian memiliki jumlah kemasan sendiri. Kertas minyak dan kedua jenis Box isi 5 otomatis mengikuti jumlah Box isi 5.
Isi jumlah loyang untuk melihat perkiraan pengurangan stok.

Rekap target harian

Setiap outlet menampilkan jumlah per varian sekaligus total seluruh loyang dari semua input pada tanggal tersebut.

Belum ada target untuk tanggal ini.

Tempel Stock Opname Harian

Tempel seluruh pesan stock opname dari grup kerja. Aplikasi akan mengganti hanya bagian *INSAN* dengan stok terbaru dari database, sementara bagian rekan kerja dan catatan lain tetap dipertahankan.

Pengurangan stok manual

Gunakan jika ada barang rusak, hilang, dipakai di luar produksi, atau koreksi stok. Masukkan alasan agar mudah dilacak.

Riwayat transaksi

Admin dapat menghapus transaksi yang salah. Stok akan dikembalikan sesuai perubahan transaksi. Penghapusan membutuhkan koneksi server.

🛡️ Pencadangan & Pemulihan

Kelola file cadangan database INSAN di halaman tersendiri. File mencakup stok, akun pengguna, transaksi, pengaturan, dan riwayat. Simpan file di tempat aman.

🛡️ Cadangkan & Pulihkan Data

Buat file khusus .insanbackup yang berisi stok, akun pengguna, transaksi, pengaturan, dan riwayat. Simpan file ini di tempat aman. Pemulihan akan mengganti database aktif sesuai isi file.

Fitur ini hanya tersedia untuk admin saat terhubung ke server.

Pusat informasi fitur, keunggulan, versi, dan catatan pembaruan aplikasi.

Fitur aplikasi

📦 Manajemen stok

Pantau jumlah persediaan setiap jenis barang dalam satu dashboard.

🚚 Barang masuk

Catat penerimaan barang berdasarkan pack, isi per pack, dan tambahan satuan.

Catat target dan kebutuhan bahan/kemasan produksi berdasarkan varian.

📊 Laporan

Lihat ringkasan stok dan laporan aktivitas persediaan.

🧾 Riwayat transaksi

Telusuri transaksi barang masuk, pengurangan stok, dan produksi.

✍️ Stok manual

Catat penyesuaian stok secara manual sesuai hak akses akun.

👥 Admin & staff

Pemisahan akses pengguna berdasarkan peran akun.

🔄 Pembaruan aplikasi

Periksa versi terbaru dari GitHub dan jalankan update oleh admin.

Keunggulan

  • Offline-first: tetap dapat melihat data tersimpan dan mencatat perubahan saat koneksi terputus.
  • Sinkronisasi otomatis: antrean transaksi dikirim ke server saat perangkat kembali online.
  • Data lokal: backend berjalan di Termux dan menyimpan database pada perangkat server.
  • Ringan: menggunakan Node.js, Express, dan frontend web tanpa bergantung pada layanan cloud berbayar.
  • Tampilan adaptif: mendukung tema terang/gelap dan navigasi yang ramah perangkat seluler.

Commit terbaru dari GitHub

Lihat commit pada branch main. Admin dapat menerapkan commit terbaru setelah memastikan antrean transaksi sudah tersinkron.
