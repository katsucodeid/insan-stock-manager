MENU UTAMA

Ringkasan persediaan

Pantau stok yang tersedia. Status Aman berarti stok masih di atas batas minimum. Jika di bawah minimum, segera rencanakan pengadaan.

Stok tersimpan

Catat barang masuk

Total barang dihitung otomatis: (jumlah pack × isi per pack) + tambahan pcs. Contoh: 2 pack × 100 pcs + 5 pcs = 205 pcs.

Catat target produksi

Pilih outlet, lalu isi jumlah setiap varian. Total seluruh loyang dihitung otomatis dan ditampilkan sebelum target disimpan.

Jumlah loyang per varian

Contoh: request 9 box isi 5, 1 box isi 3 → isi Box isi 3 = 1, Box isi 5 = 9, kertas = 9.
Isi jumlah loyang untuk melihat perkiraan pengurangan stok.

Rekap target harian

Setiap outlet menampilkan jumlah per varian sekaligus total seluruh loyang dari semua input pada tanggal tersebut.

Belum ada target untuk tanggal ini.

Laporan INSAN siap salin

Pengurangan stok manual

Gunakan jika ada barang rusak, hilang, dipakai di luar produksi, atau koreksi stok. Masukkan alasan agar mudah dilacak.

Riwayat transaksi

Admin dapat menghapus transaksi yang salah. Stok akan dikembalikan sesuai perubahan transaksi. Penghapusan membutuhkan koneksi server.
