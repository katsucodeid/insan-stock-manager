# Aturan stok INSAN
- Posisi awal seed: box3 3861, box5outer 3427, box5inner 3559, paper 1686, mika 210.
- Produksi normal: setiap loyang memakai 2 pcs dari box3, box5outer, box5inner, dan paper.
- Request khusus: angka yang diinput adalah jumlah pcs aktual untuk satu transaksi target dan menggantikan pengurangan normal. Box isi 5 berlaku sama untuk luar/slongsong dan dalam/tatakan polos.
- Mika tidak berkurang otomatis.
- Barang masuk: pack * isi per pack + tambahan.
- Sistem menolak transaksi yang membuat stok negatif.
- Jangan menghapus transaksi database manual untuk koreksi stok.
